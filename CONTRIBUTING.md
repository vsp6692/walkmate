# Contributing
Use Node 22.13+ and install dependencies in apps/mobile with npm ci. Keep changes small and run TypeScript checking and an Expo export. Validate native audio and GPS on a real device.

Priorities are a cancellable conversation controller, a user-configured backend adapter, speech recognition, and reliable Android background audio. Preserve fictional character identity, explicit recording consent, optional location, and account-free setup. Never commit provider secrets or unlicensed voices or likenesses.
